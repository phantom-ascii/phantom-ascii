# phantom-ascii

15 · UK · Hardware, CAD & Game Dev

I design custom PCBs, 3D-printed hardware, and 2D games from scratch—no web generators, no auto-routing shortcuts.

### Projects
* **[S.O-Dongle](https://github.com/phantom-ascii/S.O-Dongle)** — Custom USB-A edge-connector PCB and 3D-printed enclosure with a CH552G microcontroller, SMD tactile switch, and 0.91" I2C OLED.
* **cosmic-key** — Custom 68-key (65%) mechanical keyboard running a Raspberry Pi Pico, rotary encoder, and OLED inside a heavy-fill 3D-printed case.
* **nosmos** — Compact 100×100mm Cartesian bedslinger 3D printer built around 2020 extrusions, MGN12 linear rails, and NEMA 17 steppers.
* **ae_axis** — Modular 12.2" Linux 2-in-1 tablet with a detachable magnetic keyboard/mouse module powered by a LattePanda Mu.
* **RoboTrip** — Two-wheeled self-balancing robot driven by an ESP32, BNO055 IMU, A4988 drivers, and NEMA 17 motors.
* **Godot Micro-Games** — 2D indie games written in GDScript with hand-drawn Aseprite pixel art and custom SFX.

### Stack & Tools
* **EDA / CAD:** KiCad 8 & 10, Onshape
* **Code / Firmware:** C++, GDScript, Python, Lua, KMK / Arduino
* **Art / Environment:** Aseprite, Ubuntu Linux
